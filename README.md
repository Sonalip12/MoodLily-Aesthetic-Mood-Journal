# 🌸 MoodLily – Aesthetic Mood Journal

MoodLily is a modern full-stack aesthetic mood journaling web application designed for students and young users who want a cozy digital space to track emotions, write journals, and relax productively.

# 🌸 MoodLily – Aesthetic Mood Journal

MoodLily is a modern full-stack aesthetic mood journaling web application designed for students and young users who want a cozy digital space to track emotions, write journals, and relax productively.

Inspired by Pinterest aesthetics, Notion-style minimalism, and cozy productivity apps, MoodLily combines wellness, journaling, analytics, and relaxing UI experiences into one beautiful platform.

---

# ✨ Features

## 🔐 Authentication System

- User Signup & Login
- Secure password hashing
- Session management
- Protected routes

## 😊 Mood Tracking

- Emoji-based mood selection
- Mood history with timestamps
- Daily mood logging
- Mood streak tracker

## 📖 Daily Journal

- Create journal entries
- Edit & delete journals
- Mood-tagged entries
- Search & filter journals

## 📊 Analytics Dashboard

- Weekly mood analytics
- Mood trends visualization
- Pie charts & graphs
- Productivity insights

## 🎵 Relax Mode

- Lofi music section
- Focus timer
- Breathing animations
- Calming quotes
- Animated relaxing UI

## 🎀 Aesthetic UI

- Glassmorphism effects
- Pastel pink & lavender palette
- Floating sparkles/stars
- Responsive design
- Smooth animations
- Theme toggle
